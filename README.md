### 🎯 Guess the JavaScript Output!

```javascript
// 🤔 What does this print?

console.log([] + []);              // ?

// "object"   ← famous JS quirk

// ""         ← empty string (arrays become strings!)
```

```yaml
name: Generate Snake Animation

    - cron: "0 */12 * * *"

  push:

      - main

    timeout-minutes: 10

          force_orphan: true
```
